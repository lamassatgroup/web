# Taxi 9.5 — طريقة التشغيل والنشر

## 1) تعديل البريد ورقم واتساب
افتح `index.html` وابحث عن `const CONFIG` في نهاية الملف:
- `email`: ضع بريد Gmail الذي تريد استقبال الحجوزات عليه بدل `YOUR_EMAIL@example.com`.
- `whatsapp`: الرقم بصيغة دولية من دون + أو مسافات. الرقم الحالي مضبوط على 33612736444.

## 2) تفعيل البريد مجاناً عبر FormSubmit
1. لا تحتاج إلى إنشاء خادم أو ربط SMTP.
2. بعد وضع بريدك في `CONFIG.email`، ارفع الموقع وافتحه من رابط Vercel.
3. املأ نموذج الحجز مرة واحدة واضغط «Envoyer par e-mail».
4. ستصلك رسالة تفعيل من FormSubmit إلى Gmail؛ افتحها واضغط رابط التفعيل.
5. بعد التفعيل، كل طلب جديد يصل إلى البريد. تحقق من Spam/Junk عند الحاجة.

ملاحظة: الخطة المجانية في FormSubmit.co لا تتطلب تسجيل حساب، لكن يجب تأكيد البريد أول مرة. راجع https://formsubmit.co/documentation .

## 3) التاريخ والساعة وزر WhatsApp
يتضمن النموذج اختيار تاريخ الرحلة (لا يسمح بتاريخ سابق) واختيار الساعة والدقيقة بحرية. تظهر القيم ضمن رسالة البريد الإلكتروني ورسالة WhatsApp. الزر الثاني يفتح محادثة WhatsApp على الرقم المضبوط، ويجهز رسالة تحتوي على الاسم والهاتف والتاريخ والساعة ونقطة الانطلاق. لا يوجد حقل وجهة في النموذج كما طلبت.

## 4) النشر على GitHub وVercel
1. أنشئ مستودعاً جديداً في GitHub وارفع محتويات مجلد `taxi95-site` (وليس ملف ZIP فقط).
2. في Vercel اختر Add New → Project ثم Import لمستودع GitHub.
3. اترك Framework Preset على Other، وBuild Command فارغاً، وOutput Directory فارغاً أو `.` ثم Deploy.
4. بعد التعديل في GitHub، سيعيد Vercel النشر تلقائياً.

## 5) تغيير المدن أو التصميم
- المدن: ابحث عن قائمة `locations` داخل `index.html`، ثم عدّل خيارات القائمة وبطاقات المناطق.
- الشعار: استبدل `assets/taxi95-logo.jpg` بشعارك الجديد مع الاحتفاظ بالاسم نفسه.
- الصورة: غيّر رابط `src` في عنصر `img` ذي الصنف `hero-photo`. الصورة الحالية من Pexels (Tim Samuel): https://www.pexels.com/photo/taxi-car-on-street-in-city-5835272/
- الألوان: في بداية CSS عدّل `--site-primary` للأخضر و`--site-secondary` للذهبي.
- النصوص: ابحث عن النص الفرنسي في HTML والنص الإنجليزي في `data-en`.

## الملفات
- `index.html`: الموقع كاملاً (HTML/CSS/JS).
- `assets/taxi95-logo.jpg`: شعار Taxi 9.5 المرسل.

لا تضع كلمات مرور Gmail أو مفاتيح خاصة داخل الموقع. FormSubmit يستقبل النموذج ويرسل بيانات الحجز إلى البريد الذي تؤكده.
